Start small

Try it on localhost.

Download an archive for your machine, extract it, and open a terminal in the extracted directory. Or build from source with cargo build --release and use ./target/release/codeenv below.

Local development · no Cloudflare setup needed
cat > dev.toml <<'CONFIG'
listen = "127.0.0.1:7690"
root = "."
[auth]
mode = "insecure"
user = "dev@example.com"
CONFIG

./codeenv -c dev.toml

Then open localhost:7690.

Built for people you trust.

Every signed-in user gets a full shell under the same Unix account. codeenv is for a personal server or a trusted team. It does not isolate users from each other.
