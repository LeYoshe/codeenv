        Open a terminal in an explorer folder, or run a command from the top bar.

        Shortcuts work outside terminal and editor views. The keyboard button enables fullscreen to pass through keys reserved by the browser.

        Alt+Shift+P
        Palette: terminals, commands, ports

        Close tab
        Alt+Shift+←/→
        Previous / next tab
        Alt+Shift+1…9
        Go to tab n
        Alt+Shift+E
        Focus explorer
        Alt+Shift+F
        Search files
        Alt+Shift+B
        Toggle sidebar
